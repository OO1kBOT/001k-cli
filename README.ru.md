## Возможности

- **Полное покрытие API** — депозиты, выводы, свопы, переводы, лимитные ордера, AML-проверки, баланс и журнал операций.
- **Встроенный AI-агентский скилл** — скилл (`001k-cli`) управляет CLI из Claude Code и любого агента на естественном языке.
- **Безопасность по умолчанию** — подпись запросов HMAC-SHA256; секретный ключ используется только локально и никогда не передаётся и не логируется.
- **Несколько профилей** — именованные профили в `~/.001k/` (глобально) или `./.001k/` (проект), выбираются через `--profile`.
- **Только HTTPS** — CLI не отправит учётные данные по протоколу, отличному от `https://`.
- **JSON-вывод** — структурированный JSON в stdout с понятными кодами выхода (0/1/2/3) — направляйте в `jq` или любую автоматизацию.
- **Готов к CI/CD** — учётные данные через переменные `OO1K_ACCESS_KEY` / `OO1K_SECRET_KEY` для неинтерактивных пайплайнов.

## Быстрый старт

```bash
# 1. Установить CLI глобально
npm install -g 001k-cli
# или другим менеджером пакетов:
# pnpm add -g 001k-cli  |  yarn global add 001k-cli  |  bun add -g 001k-cli

# 2. Авторизоваться (интерактивный ввод ключа доступа и секретного ключа)
001k auth login

# 3. (Опционально) Установить AI-агентский скилл для Claude Code
npx skills add OO1kBOT/001k-cli
```

## Как это работает

Проект состоит из двух слоёв:

1. **CLI** (`001k`) — самостоятельный инструмент командной строки, который подписывает
   запросы HMAC-SHA256, обращается к API 001k.bot и возвращает структурированный JSON.
2. **Скилл** (`001k-cli`) — набор инструкций, который обучает AI-агента (например,
   Claude Code), *когда* и *как* вызывать CLI. Агент читает скилл, интерпретирует
   запросы на естественном языке и преобразует их в команды `001k`.

Все секреты остаются локально. CLI подписывает запросы вашими HMAC-ключами; ни скилл,
ни агент никогда не видят исходных учётных данных.

## Авторизация

```bash
# Интерактивный вход — запрашивает ключ доступа и секретный ключ
001k auth login

# Именованный профиль / область проекта
001k auth login --profile staging
001k auth login --scope project
```

Учётные данные разрешаются в следующем порядке (побеждает первое совпадение):

1. `--profile <имя>`
2. `--profile-path <файл>`
3. Автовыбор, если существует ровно один профиль
4. Ошибка, если профилей несколько (укажите `--profile`)
5. Переменные окружения `OO1K_ACCESS_KEY` / `OO1K_SECRET_KEY` (для CI/CD)

Профили хранятся в JSON с правами только для владельца:

- Глобально: `~/.001k/profiles/<имя>.json`
- Проект: `./.001k/profiles/<имя>.json` (переопределяет глобальный профиль с тем же именем)

> Ключи хранятся **в открытом виде** (файлы `0600`). Не синхронизируйте `~/.001k/`
> с облачными бэкапами и используйте ключи с минимальными правами. См. [SECURITY.md](./SECURITY.md).

## Конфигурация

| Переменная   | По умолчанию             | Описание                                |
| ------------ | ------------------------ | --------------------------------------- |
| `OO1K_ACCESS_KEY` | —                        | Ключ доступа к API (только для CI/CD)    |
| `OO1K_SECRET_KEY` | —                        | Секретный ключ API (только для CI/CD)    |
| `OO1K_BASE_URL`   | `https://api.001k.world` | Базовый URL API (должен быть `https://`) |

Для локального использования предпочтителен `001k auth login`. Базовый URL должен
использовать HTTPS (localhost — исключение для тестирования).

## Использование с AI-агентами

Скилл работает с **любым AI-агентом, способным выполнять команды оболочки** — Claude Code, Cursor, Windsurf, Codex и другими. После установки агент преобразует естественный язык в вызовы CLI.

| Запрос                          | Команда CLI                                             |
| ------------------------------- | ------------------------------------------------------- |
| «Проверь мой баланс»            | `001k balance`                                          |
| «Покажи направления свопов»     | `001k swap directions`                                  |
| «Обменяй 0.01 BTC на USDT»      | `001k swap create --direction <код> --spend-amount 0.01` |
| «Покажи последние депозиты»     | `001k deposit list --limit 10`                          |
| «Отмени лимитный ордер ABC123»  | `001k limit-order cancel --code ABC123`                 |
| «Проверь адрес 0x… по AML»      | `001k aml create --token 1 --address 0x…`               |

> `--direction` для свопа — это `code` из `001k swap directions` (не название пары).
> `--token` для AML — числовой id из `001k aml token`.

### Настройка с Claude Code

> `npx skills add` устанавливает скилл для Claude Code. Другие агенты могут использовать тот же скилл — укажите им на `skills/001k-cli/SKILL.md` и добавьте его в контекст агента; команды CLI идентичны.


```bash
# 1. Убедитесь, что CLI установлен и авторизован
001k auth status

# 2. Установите скилл
npx skills add OO1kBOT/001k-cli

# 3. Запустите Claude Code и спрашивайте
claude
> Покажи мой баланс и последние свопы
```

## Устранение неполадок

- **`No profile found.` / `No credentials found`** — выполните `001k auth login` или
  задайте `OO1K_ACCESS_KEY` / `OO1K_SECRET_KEY`. Проверьте через `001k auth status`.
- **`ECONNREFUSED` / `ENOTFOUND` / `ETIMEDOUT`** — проверьте соединение и доступность
  `OO1K_BASE_URL` (по умолчанию `https://api.001k.world`). Сетевые сбои завершаются
  с кодом 3 и выводят `{ "network_error": true, "message": "..." }` в stderr.
- **Ошибка небезопасного base URL** — `OO1K_BASE_URL` должен использовать `https://`
  (localhost — исключение).
- **Версия Node** — CLI требует Node.js 20+ (`node --version`).

Ошибки API возвращаются в структурированном JSON с кодом и сообщением. Используйте
`--help` для просмотра флагов.
